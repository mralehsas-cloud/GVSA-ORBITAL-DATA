# GVSA ORBITAL DATA — الإصلاح التشغيلي R1

هذه حزمة استبدال لمستودع mralehsas-cloud/GVSA-ORBITAL-DATA فقط.
ليست نسخة واجهة GVSA للموقع أو تطبيق ويندوز، وليست إصلاحًا معتمدًا لمستودع GVSA-AUTO-UPDATE غير المتاح.

## التثبيت
1. احتفظ بنسخة من ملفات المستودع الحالية.
2. انسخ مجلدي automation و.github من الحزمة إلى جذر مستودع GVSA-ORBITAL-DATA مع الاستبدال. مجلد .github قد يكون مخفيًا.
3. لا تحذف أو تستبدل automation/state.json أو orbital/. الحزمة لا تتضمنهما عمدًا حتى لا تعيد بيانات قديمة أو تمسح مواعيد انتظار المزود.
4. نفذ الاختبارات من جذر المستودع باستخدام Python 3.12:
   python -m unittest discover -s automation -p 'test_*.py' -v
5. ارفع التعديلات بعد نجاح الاختبارات. ملف workflow موجود كما هو في المصدر؛ التعديل الإنتاجي محصور في ملفي Python.
6. اقرأ automation/state.json الحالي واحترم no_request_before_unix لكل مصدر. لا تمسح المهلة ولا تنفذ طلبات تجريبية متكررة.
7. استخدم Actions > GVSA - public ISS and Starlink OMM refresh > Run workflow على main بعد انتهاء المهلة ووجود التعديل في main. إعادة تشغيل تشغيل قديم لا تختبر بالضرورة النسخة المعدلة.

## معيار القبول
- تمر جميع الاختبارات الـ18.
- أثناء PROVIDER_BACKOFF مع خطأ محفوظ تبقى المهمة فاشلة عمدًا ويظل error ظاهرًا؛ هذا يمنع تفسير الانتظار على أنه تعافٍ.
- لا يُرسل طلب أثناء مهلة الانتظار، ولا تتغير ملفات OMM عند فشل المزود.
- بعد انتهاء المهلة، افحص سجل الطلب الفعلي: PUBLISHED أو UNCHANGED_OLDER_OR_EQUAL_EPOCH يعني وصول استجابة مقبولة، أما SIX_HOUR_COOLDOWN فلا يعني إجراء تنزيل جديد.
- تحقق من EPOCH داخل iss.json وstarlink-sample.json وصلاحية البيانات للاستخدام المقصود؛ updated_at_utc في ملف الحالة ليس عمر المدار.
- إن عاد HTTP 403 فالرفض الخارجي ما زال قائمًا. وإن عاد خطأ شبكة فستظهر الآن فئته وسببه لتحديد الإجراء التالي. لا تعطل TLS ولا تضف حلقات إعادة طلب.

## نطاق التعديل
- omm_source.py: تضمين نوع وسبب URLError، مع إبقاء HTTP 403 كما هو.
- publish.py: إرجاع رمز فشل أثناء انتظار خطأ سابق بدل النجاح المضلل.
- test_operational.py: ثمانية اختبارات إضافية دون شبكة.
- الإبقاء على الاختبارات العشرة الأصلية، وفترة الطلب 6 ساعات، وانتظار الخطأ 24 ساعة، والتحقق من بيانات المدار كما هي.
